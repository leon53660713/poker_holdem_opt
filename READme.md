# Optimize Hold'em Game Policy / 最佳化德州撲克策略

## Introduction / 簡介
To become a profitable player in Texas Hold'em, <br>
this project leverages **Monte Carlo Simulation** to estimate win probabilities <br>
and then applies **Reinforcement Learning (PPO)** to optimize preflop decision-making policies. <br>

為了成為能長期獲利的德州撲克玩家， <br>
本專案利用 **蒙地卡羅模擬（Monte Carlo Simulation）** 估算勝率--`simulate_poker.ipynb`， <br>
並結合 **強化學習（PPO, Proximal Policy Optimization）**--`RL_poker.ipynb`， <br>
自動學習最佳決策策略。 <br>
